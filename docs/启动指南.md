## 环境准备

| 环境 | 要求 |
|------|------|
| Node.js | >= 18.0.0（推荐 20+） |
| npm | >= 9.0.0（随 Node.js 一起安装） |
| 浏览器 | Chrome / Edge / Firefox 最新版 |

检查本地环境：

```bash
node --version
npm --version
```

## 安装依赖

在项目根目录下运行：

```bash
cd personal-website
npm install
```

安装完成后，项目依赖如下（来自 `package.json`）：

| 依赖 | 版本 | 用途 |
|------|------|------|
| vite | ^8.0.12 | 开发服务器与构建工具 |
| three | ^0.184.0 | 3D 渲染引擎（动态背景） |
| gsap | ^3.15.0 | 动画引擎（滚动/入场动画） |

## 开发模式启动

### 启动开发服务器

```bash
npm run dev
```

Vite 开发服务器默认会在 `http://localhost:3000` 启动，并自动在浏览器中打开。

### 访问页面

| 页面 | URL | 说明 |
|------|-----|------|
| **展示端（前台）** | `http://localhost:3000/` | 访客看到的个人网站主页 |
| **管理端（后台）** | `http://localhost:3000/admin.html` | 管理员编辑内容的后台 |

> 开发模式下修改源代码会自动热更新，无需手动刷新浏览器。

## 生产构建与预览

### 构建生产版本

```bash
npm run build
```

构建产物输出到 `dist/` 目录：

```
dist/
├── index.html              ← 展示端首页
├── admin.html              ← 管理端后台
├── assets/                 ← JS/CSS 等静态资源
├── audio/                  ← 背景音乐文件
└── favicon.svg             ← 网站图标
```

### 预览构建结果

```bash
npm run preview
```

本地预览服务器会在 `http://localhost:4173` 启动，模拟生产环境。

## 管理端使用说明

### 访问管理后台

开发环境：`http://localhost:3000/admin.html`
生产环境：`https://你的域名/admin.html`

### 管理后台功能

管理后台包含 **4 个标签页**：

#### 1. 个人资料 (profile)

| 字段 | 说明 |
|------|------|
| 姓名 | 显示在 Hero 区域和 About 区域 |
| 职位/头衔 | 显示在头像下方 |
| 个人简介 | About 区域的个人介绍文字 |
| 邮箱 | 联系方式中的邮箱 |
| GitHub 地址 | 联系方式中的 GitHub 链接 |
| 头像上传 | 支持 JPG/PNG/WebP，建议 1:1 正方形 |
| 技能标签 | 添加/删除技能名称和熟练度（0-100） |
| 工作经历 | 添加/删除工作经历（公司、职位、时间、描述） |
| 教育背景 | 添加/删除教育经历（学校、专业、时间、学位） |

#### 2. 作品管理 (works)

| 字段 | 说明 |
|------|------|
| 作品分类 | 逗号分隔的分类标签，如 "全部, 开发, 设计, 3D" |
| 作品列表 | 添加/删除作品，每项包含标题、分类、描述、标签、链接、封面图 |

#### 3. 联系方式 (contact)

| 字段 | 说明 |
|------|------|
| 邮箱 | 展示在联系区域的邮箱地址 |
| GitHub | 展示在联系区域的 GitHub 链接 |
| 微信二维码 | 上传微信二维码图片，建议 1:1 正方形 |

#### 4. 网站设置 (settings)

| 字段 | 说明 |
|------|------|
| 网站标题 | 浏览器标签页显示的标题 |
| 网站描述 | SEO meta description |
| Hero 打字机文字 | 首页 Hero 区域逐字输出的文字 |
| Hero 副标题 | Hero 区域的副标题 |
| Hero 描述 | Hero 区域的描述文字 |
| 默认背景主题 | 流体渐变 / 深空星波 / 海浪涌动 |

### 管理端操作按钮

| 按钮 | 功能 |
|------|------|
| **导入备份** | 从 JSON 文件恢复全部数据 |
| **导出备份** | 将所有数据导出为 JSON 文件下载 |
| **恢复默认** | 清除所有自定义数据，恢复为 JSON 配置文件的默认值 |
| **保存全部** | 保存当前所有修改到浏览器 localStorage |
| **查看网站** | 在新标签页打开展示端首页 |

### 数据持久化说明

- 管理后台的数据存储在**浏览器 localStorage** 中
- 首次访问时，使用 `config/` 目录下的 JSON 文件作为默认值
- 修改后必须点击「保存全部」才会持久化
- 清除浏览器缓存会导致自定义数据丢失，建议定期导出备份

## 常见问题

### Q: 开发服务器启动失败怎么办？
A: 检查 Node.js 版本 >= 18，然后删除 `node_modules` 重新安装：
```bash
rm -rf node_modules
npm install
```

### Q: 修改了配置文件但页面没变化？
A: 开发模式下修改 `config/` 下的 JSON 文件需要手动刷新页面。如果修改了 `src/` 下的代码会自动热更新。

### Q: 管理后台保存后前台没更新？
A: 刷新前台页面即可。管理后台和前台共用同一个 localStorage，数据在同一浏览器下互通。

### Q: 如何在手机上预览？
A: 开发服务器默认只监听 `localhost`。可以修改 `vite.config.js`：
```js
server: {
  host: '0.0.0.0',  // 允许局域网访问
  port: 3000
}
```
然后在手机上通过 `http://你的局域网IP:3000` 访问。
