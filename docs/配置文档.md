## 配置文件总览

所有配置文件位于项目根目录的 `config/` 文件夹下：

```
config/
├── profile.json     ← 个人资料（姓名、技能、经历、教育）
├── works.json       ← 作品集（标题、描述、分类、标签、封面）
├── contact.json     ← 联系方式（邮箱、GitHub、微信二维码）
├── site.json        ← 网站设置（标题、SEO、Hero 文字）
├── themes.json      ← 背景主题颜色配置
└── assets/          ← 静态资源目录
    ├── avatar.jpg
    ├── qrcode.png
    └── works/
        ├── project1-cover.jpg
        └── ...
```

### 数据加载优先级

```
localStorage（用户通过管理后台保存的自定义数据）
    ↓ 优先
JSON 配置文件（config/ 目录下的默认值）
```

- 如果用户通过管理后台保存过数据，则使用 localStorage 中的数据
- 如果是首次访问或 localStorage 中没有数据，则回退到 JSON 配置文件
- 管理后台的「恢复默认」按钮会清除 localStorage，重新使用 JSON 配置

### 字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `name` | string | 是 | 姓名，显示在 Hero 区域和 About 区域 |
| `title` | string | 是 | 职位/头衔，显示在头像下方 |
| `avatar` | string | 否 | 头像图片路径（相对于 `config/` 或 `public/`） |
| `bio` | string | 否 | 个人简介，显示在 About 区域 |
| `email` | string | 否 | 邮箱地址 |
| `github` | string | 否 | GitHub 个人主页链接 |
| `skills` | array | 否 | 技能列表，每项包含名称和熟练度（0-100） |
| `experience` | array | 否 | 工作经历列表 |
| `education` | array | 否 | 教育背景列表 |

### skills 数组项

| 字段 | 类型 | 说明 |
|------|------|------|
| `name` | string | 技能名称 |
| `level` | number | 熟练度百分比（0-100），控制进度条宽度 |

### experience 数组项

| 字段 | 类型 | 说明 |
|------|------|------|
| `company` | string | 公司名称 |
| `role` | string | 职位 |
| `period` | string | 时间段，如 "2023 - 至今" |
| `description` | string | 工作描述 |

### education 数组项

| 字段 | 类型 | 说明 |
|------|------|------|
| `school` | string | 学校名称 |
| `major` | string | 专业 |
| `period` | string | 时间段，如 "2016 - 2020" |
| `degree` | string | 学位，如 "本科"、"硕士" |

## 作品集配置 (works.json)

**文件位置：** `config/works.json`

### 完整结构

```json
{
  "categories": ["全部", "开发", "设计", "3D"],
  "items": [
    {
      "id": 1,
      "title": "智能数据看板",
      "description": "基于Vue3+Three.js的数据可视化平台。",
      "category": "开发",
      "cover": "",
      "tags": ["Vue3", "Three.js", "WebSocket"],
      "link": ""
    },
    {
      "id": 2,
      "title": "3D虚拟展厅",
      "description": "沉浸式线上美术馆，支持第一人称漫游。",
      "category": "3D",
      "cover": "",
      "tags": ["Three.js", "GLSL", "Blender"],
      "link": ""
    }
  ]
}
```

### 字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `categories` | array | 是 | 分类列表，首项必须为"全部"（过滤作品时使用） |
| `items` | array | 是 | 作品列表 |

### items 数组项

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `id` | number | 是 | 作品唯一 ID，用于封面图关联 |
| `title` | string | 是 | 作品标题 |
| `description` | string | 否 | 作品描述 |
| `category` | string | 是 | 所属分类，必须是 `categories` 中的值（"全部"除外） |
| `cover` | string | 否 | 封面图路径（目前使用 localStorage 管理，JSON 中可留空） |
| `tags` | array | 否 | 标签列表，用于作品卡片底部的徽标展示 |
| `link` | string | 否 | 作品链接，点击作品卡片可跳转 |

### 分类过滤逻辑

- 前台页面顶部渲染的筛选按钮来自 `categories` 数组
- 首项 "全部" 显示全部作品
- 点击其他分类按钮时，只展示 `category` 匹配的作品
- 每项作品的 `category` 必须与 `categories` 中的分类一致

## 联系方式配置 (contact.json)

**文件位置：** `config/contact.json`

```json
{
  "wechat_qrcode": "assets/qrcode.png",
  "email": "example@email.com",
  "github": "https://github.com",
  "weibo": "",
  "twitter": ""
}
```

### 字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `wechat_qrcode` | string | 否 | 微信二维码图片路径（用于前台显示） |
| `email` | string | 否 | 邮箱地址，点击可唤起邮件客户端 |
| `github` | string | 否 | GitHub 链接，点击在新标签页打开 |
| `weibo` | string | 否 | 微博链接（预留字段，前台未渲染） |
| `twitter` | string | 否 | Twitter 链接（预留字段，前台未渲染） |

> 注意：`weibo` 和 `twitter` 字段目前在前台页面中没有对应的渲染逻辑，如需展示需要自行扩展 `main.js` 中的 `bindContactLinks` 函数。

## 网站设置配置 (site.json)

**文件位置：** `config/site.json`

```json
{
  "title": "个人展示网站",
  "subtitle": "创意开发者",
  "description": "用代码构建数字世界，用设计诠释用户体验",
  "language": "zh-CN",
  "keywords": "前端开发, 3D可视化, WebGL, Three.js"
}
```

### 字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `title` | string | 是 | 网站标题，显示在浏览器标签页和 SEO 标题 |
| `subtitle` | string | 是 | 副标题，显示在 Hero 区域打字机文字下方 |
| `description` | string | 是 | 网站描述，用于 `<meta name="description">`（SEO） |
| `language` | string | 否 | 语言代码，默认 "zh-CN" |
| `keywords` | string | 否 | SEO 关键词，逗号分隔 |

> 注意：`subtitle` 字段在 JSON 中为 "创意开发者"，但在管理后台的「网站设置」中有独立的「Hero 副标题」输入框，管理后台保存的 `subtitle` 值会覆盖 JSON 中的值。

## 主题配置 (themes.json)

**文件位置：** `config/themes.json`

```json
{
  "default": "fluid",
  "themes": {
    "fluid": {
      "name": "流体渐变",
      "type": "shader",
      "colors": ["#1a1a2e", "#e94560", "#0f3460"]
    },
    "cosmos": {
      "name": "深空星波",
      "type": "shader",
      "colors": ["#0a0a1a", "#4a4ae8", "#1a1a4e"]
    },
    "ocean": {
      "name": "海浪涌动",
      "type": "shader",
      "colors": ["#0a1a2a", "#00b4d8", "#0077b6"]
    },
    "custom": {
      "name": "自定义",
      "type": "image|video",
      "src": "assets/backgrounds/custom-bg.jpg"
    }
  }
}
```

### 字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `default` | string | 是 | 默认主题 key，必须对应 `themes` 中的某个 key |
| `themes` | object | 是 | 主题字典，key 为主题标识符 |

### themes 主题项

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `name` | string | 是 | 主题显示名称（管理后台下拉菜单用） |
| `type` | string | 是 | 主题类型：`shader`（Shader 渐变）/ `image`（图片）/ `video`（视频） |
| `colors` | array | type=shader | 主题颜色数组（3 个十六进制颜色值），传给 Shader 用于颜色渐变 |
| `src` | string | type=image/video | 背景图片或视频路径 |

### 内置主题

| 主题 key | 中文名 | 颜色方案 |
|----------|--------|----------|
| `fluid` | 流体渐变 | 深紫 → 亮红 → 深蓝 |
| `cosmos` | 深空星波 | 深黑 → 紫色 → 深紫 |
| `ocean` | 海浪涌动 | 深海蓝 → 亮青 → 深蓝 |

### 切换主题

- **前台**：点击导航栏右侧的太阳图标按钮循环切换三种 Shader 主题
- **管理后台**：在「网站设置」tab 的下拉菜单中选择默认主题
- 主题切换会影响：流体背景 Shader、环境粒子颜色、漂浮几何体颜色、Hero 3D 粒子环颜色

## 资源文件管理

### 目录结构

```
config/assets/           ← 配置文件引用的静态资源（本地开发用）
├── avatar.jpg           ← 头像
├── qrcode.png           ← 微信二维码
└── works/               ← 作品封面图目录

public/                   ← Vite 公共目录（构建时会复制到 dist/）
├── favicon.svg           ← 网站图标
└── audio/
    └── bg-music.mp3      ← 背景音乐
```

### 使用说明

1. **头像和二维码**：JSON 配置文件中的 `avatar` 和 `wechat_qrcode` 路径是相对于 `config/` 目录的，但 Vite 构建时不会处理 `config/assets/` 中的文件。实际部署时需要通过管理后台上传，数据以 base64 形式存储在 localStorage 中。

2. **作品封面图**：同上，通过管理后台上传，存储在 localStorage 中。

3. **背景音乐**：将 MP3 文件放入 `public/audio/` 目录，重命名为 `bg-music.mp3`，然后重新构建。

4. **网站图标**：替换 `public/favicon.svg` 即可。

## 存储机制说明

### localStorage 键名对照表

| localStorage key | 存储内容 | 对应 JSON 配置文件 |
|-----------------|----------|-------------------|
| `pw_profile` | 个人资料对象 | `config/profile.json` |
| `pw_works` | 作品集对象 | `config/works.json` |
| `pw_contact` | 联系方式对象 | `config/contact.json` |
| `pw_site` | 网站设置对象 | `config/site.json` |
| `pw_theme` | 主题标识符字符串 | `config/themes.json` |
| `pw_avatar` | 头像图片 base64 data URL | — |
| `pw_qrcode` | 二维码图片 base64 data URL | — |
| `pw_work_covers` | 作品封面字典 `{workId: base64}` | — |

### 数据流图

```
用户操作管理后台
     │
     ▼
点击「保存全部」
     │
     ├──→ saveProfile()  → localStorage.setItem('pw_profile', ...)
     ├──→ saveWorks()    → localStorage.setItem('pw_works', ...)
     ├──→ saveContact()  → localStorage.setItem('pw_contact', ...)
     ├──→ saveSite()     → localStorage.setItem('pw_site', ...)
     ├──→ saveTheme()    → localStorage.setItem('pw_theme', ...)
     ├──→ saveAvatar()   → localStorage.setItem('pw_avatar', ...)
     ├──→ saveQRCode()   → localStorage.setItem('pw_qrcode', ...)
     └──→ saveWorkCover() → localStorage.setItem('pw_work_covers', ...)
                                                                   │
                    前台页面加载时                                    │
                         │                                           │
                         ▼                                           │
                    loadAllData()                                    │
                         │                                           │
                         ├──→ getProfile() → localStorage 有数据?    │
                         │       ├── 是 → 使用 localStorage 数据     │
                         │       └── 否 → fetch('/config/profile.json')
                         │                                           │
                         └── 同理处理 works/contact/site/theme       │
                                                                     │
                    前台渲染页面 ←───────────── 绑定到 DOM ←──────────┘
```

## 数据流架构

### 启动流程

```
index.html / admin.html
    │
    ▼
DOMContentLoaded
    │
    ▼
loadAllData()
    │
    ├── localStorage 有数据? → 使用 localStorage
    │   └── 无数据 → fetch JSON 配置文件
    │
    ▼
main.js: bindAllContent()           admin.js: populateProfile()
         │                                   populateWorks()
         ├── bindProfile()                   populateContact()
         ├── renderWorks()                   populateSettings()
         ├── bindContactLinks()              populateAvatar()
         ├── loadAvatarImg()                 populateQRCode()
         └── loadQRCodeImg()
```

